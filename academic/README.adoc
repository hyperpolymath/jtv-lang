=== Key Theorems

==== Security

[arabic]
. *Code Injection Impossibility* (SECURITY_PROOFS.md §2.3)
* Code injection is grammatically impossible in JtV
. *Non-Interference* (SECURITY_PROOFS.md §3.3)
* High-security data cannot influence low-security outputs
. *Data Sandboxing* (SECURITY_PROOFS.md §5)
* Data Language has no write, I/O, or system capabilities

==== Computability

[arabic]
. *Data Language Totality* (COMPUTATIONAL_THEORY.md §2.1)
* All Data expressions terminate
. *Control Language Turing-Completeness* (COMPUTATIONAL_THEORY.md §1.4)
* Control Language can simulate any Turing machine
. *Decidability Separation* (COMPUTATIONAL_THEORY.md §2)
* Termination decidable for Data, undecidable for Control

==== Type Theory

[arabic]
. *Type Safety* (TYPE_THEORY.md §3)
* Progress + Preservation theorems
. *Purity Enforcement* (TYPE_THEORY.md §5)
* @pure/@total correctly restrict side effects
. *Principal Types* (TYPE_THEORY.md §3.2)
* Every well-typed expression has a principal type

==== Reversibility

[arabic]
. *Forward-Backward Identity* (QUANTUM_REVERSIBILITY.md §2.4)
* Reversible operations compose to identity
. *Quantum Gate Simulation* (QUANTUM_REVERSIBILITY.md §3)
* Classical simulation of reversible/quantum gates
