= Reversibility (Current State) — SUPERSEDED

[IMPORTANT]
====
*Superseded 2026-11-01. Retained as a historical record only.*

This note predates the C1/C2 implementation and the v2 "(c)" Neutral bridge.
Most of its body below ("no reverse execution model", "not enforced at the
language level") no longer describes the tree.

*Two lines are still current, and the banner must not claim otherwise:*

* *"No integration with formal proofs"* — still true. No extraction or
  refinement connects the Lean/Agda model to the Rust interpreter
  (`gap-001`), and `STATUS.adoc` lists that unwired chain as a known gap.
  Only the *type-level* Echo gate is realised in code.
* *"Reversibility is not enforced at the language level"* — partly true: it is
  enforced at the *type-checker* level on the paths that typecheck first, and
  not at all in the interpreter (finding F4).

== Historical body (pre-C1/C2, do not cite)

JtV currently provides limited, partial reversibility.

== Implemented / Partially Implemented

- Property-tested reversible identities (subset)
- No guaranteed full program reversibility
- No reverse execution model
- No general undo system across all operations

== Constraints

- Reversibility is not enforced at the language level
- Round-trip identity holds only for tested cases
- No integration with formal proofs

== Summary

Reversibility is an experimental property of parts of the system,
not a guaranteed characteristic of the language.
