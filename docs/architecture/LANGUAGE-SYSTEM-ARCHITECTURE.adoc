== What the system is

=== One-paragraph summary

JtV is a Harvard-architecture language. Control is Turing-complete. Data is meant to be total and addition-only. The reference implementation is jtv-lang (Rust).

The plan puts every surface (CLI, REPL, wasm embedding, playground, LSP) behind one checked, fuelled entry point. Each supported single-carrier exact Data island then gets one semantic identity: its normal form (NF) in the free model of its carrier. Float, Complex and mixed-carrier islands have no NF theorem. Totality comes from one rank certificate. Compiled islands are checked per artefact by an independent checker, not by a compiler-correctness proof. Lean runs in CI and gates *wording*, never function.

=== IS / IS-NOT and ownership

* *jtv-lang IS* the reference implementation of JtV plus its operational proofs. It owns L0–L9 and the JtV type schema.
* *jtv-lang IS-NOT* the family type theory. Echo theory lives in echo-types. IFC lives in secret-types (not epistemic-types, not anytype).
* *typed-wasm* never depends on jtv. The `jtv-twasm → typed-wasm` direction is allowed (CONTRACT I1). No `typedwasm.*` wire change on the critical path (CONTRACT I3).
* *jtv-halting-islands-ct* is frozen. No code is merged from it. Its diode cases may only enter jtv-lang after an owner licence grant (its LICENSE is a placeholder that grants nothing, verified), or as clean-room rewrites.
* *anytype* is off-path (Echo is an effect; Q5).
* *patacl-core* is never a workspace dependency.
* *typell-jtv*'s "Julia-the-Viper" is not renamed.
* *Tropical* is not an Echo modality.

=== LABELLED ELEGANT DEFAULT ARM

*P4 Normal-Form Islands, corrected, on P2's rank certificate.*

* Each single-carrier exact Data island has one identity: its NF in the free model of its carrier's additive theory.
* One well-foundedness argument: a rank certificate that strictly decreases on every call edge (and, for `for`, a structural length measure).
* Everything else is a projection: support (explicit dependence), reverse class, loss class, cost.
* Compiled code is checked per artefact by NF equality, not by a compiler proof.

Corrections applied (from the judges and red team):

. The overflow witness is per AST node, never on the final NF. Falsifier: `(x+C)+(-C)` has NF `x`, yet the checked interpreter errors when `x+C` overflows.
. Symbolic is a word/term algebra (free semigroup over atoms closed under a formal `-(…)`), not a LinForm. The value-models doc says "no identity".
. Summaries compose by substitution with hash-consed sharing. Words do not compress, so a DAG representation is needed to keep NF size polynomial (H16).
. Scope: "single-carrier exact islands". PwLin, Float/Complex and mixed-carrier islands have no NF theorem. Their properties are not projections of a proved identity.

=== Recommended hybrid (and the departure)

* *Ordering:* P1. Holes first, cargo-only gates, one checked entry point, one executable ledger.
* *Soundness core:* P2. Computed purity levels, an emitted `TotalCert`, a Lean-compiled oracle that checks *rank consistency of the extracted call graph*.
* *Proof architecture:* the elegant arm above.
* *Target:* P3's checked-trap semantics and zero-import modules, checked by P4's independent `jtv-cert`.

*Departure, stated:* the order follows P1, not the elegant arm's R0 → rank → oracle path. Reasons: the product promise is broken on live paths today (H1, H6, H7, H13–H16), and elan was denied, so the elegant critical path cannot go green locally while every hole fix can. The `TotalCert` schema is frozen early, so the oracle drops in later without rework.

*Second departure (D6):* until typed-wasm has i64 compare/eqz/unreachable, the dependable lowering compiles only islands whose per-node bound holds for *all* i64 inputs. That is close to nothing (any `x + c` with c ≠ 0 fails). JtV has no syntax for input bounds (verified: grammar.pest has only `range_expr` for `for`). So the target lane depends on either (a) typed-wasm IR ops (owner), (b) the wasm-encoder escape hatch emitting sign-test traps now, with tw-verify as a post-check, or (c) an owner-approved checked range refinement `x: Int[lo..hi]` enforced by guard code. The elegant long-term arm is trap-preserving lowering (Err ⇔ trap).

|D3 Recursion

|D6 Compiled overflow (Q29)

|D7 Symbolic/Complex (Q31)

|Scoping (Q39, new)
|Lexical scoping: function bodies see parameters and locals only; reverse blocks act on the current frame. One ADR shared by Lean, NF and cert.
|Fail closed: reject free non-parameter identifiers in `@total`/`@pure` bodies; make `reverse` inside functions a check error
|Dependable in Wave 1; elegant by ADR.

|Name resolution (Q40, new)
|A resolver pass yields `FnId`s used by checker, purity, interpreter, cert and NF. Duplicate bare names are an error unless qualified.
|Reject any module function name that collides; stop inserting the bare alias

|Parser DoS (H13)
|Left-factor the parenthesis and data/control alternatives; add depth and token limits
